# Fashion Seller Pro

Ghana-focused business operating system for fashion sellers.

> Manage products, customers, orders, payments, deliveries and profit — all in one simple place.

## MVP
- Dashboard
- Quick Sale / Orders
- Products
- Customers
- Expenses
- Reports

## Stack
- Next.js
- TypeScript
- Tailwind CSS
- PostgreSQL
- Prisma

## Architecture
This application is intentionally separate from `Prime-HR/My-Home-`. The existing marketplace website can link to this application as a product.

## Status
Foundation initialized. Database/auth/API implementation follows the approved architecture.
